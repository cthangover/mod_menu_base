# Menu — 主菜单、选择游戏、存档与设置

Menu 是你看到的第一个屏幕：带有**开始游戏**、**读取**、**设置**、**模组与合集**和**退出**的标题菜单。在这里可以选择一款已安装的游戏，开始或继续上次的进度，读取存档，还能更改语言、声音和显示设置。其他模组也可以在这里添加自己的按钮和设置页面。

它属于始终加载的外壳，因此在任何游戏开始之前就已存在。

![主菜单：左侧是 Play、Load、Settings、Mods & Collections 和 Exit，右侧是 Cthangover 的标题画。](assets/main-menu.jpg)

## 开始游戏

**开始游戏**会打开**选择游戏**。合集里的每一款游戏都是一张卡片，上面有封面、描述、可玩状态和存档数量。

![选择游戏里的两张游戏卡片：Cthangover 和 My Novel，都显示“Ready to play”“No saves”，带 New game 和 Configure 按钮。](assets/game-picker.jpg)

- **新游戏**从游戏的第一幕场景开始。菜单会在同一个窗口内切换到该游戏的模组集合——无需重启。
- 卡片上的**继续**读取该游戏最近的存档；**存档**列出全部存档。
- **安装缺失项**在游戏缺少你尚未拥有的模组时出现，并负责下载。
- **配置**在模组管理器中打开游戏的构成方案。

当你停留在菜单上时，各游戏的模组正在后台准备；底部提示会告诉你何时启动会很快。

主菜单本身的**继续**按钮在你玩过之后才会出现：它会回到你上次玩的那个游戏和存档。

## 读取存档

**读取**一次显示一款游戏的存档；在顶部的选择器中挑选游戏，点击一个存档即可读取。

![My Novel 的读取窗口，含一个存档“Day 1, 00:00”和提示“Click a save to load it”。](assets/load.jpg)

如果自存档以来游戏的模组发生过变化，**游戏已改变**窗口会列出新增的（从头开始）、移除的（数据保留，重新启用时恢复）或已更新的内容，并在读取前备份存档。早于“游戏”概念出现的存档会出现在**没有所属游戏的存档**下；你指定它们属于哪款游戏，文件就会移过去。

在游戏进行中，存档和读取走游戏内菜单的同一个窗口：点击栏位存档，已占用的栏位在确认后覆盖，**+ 新存档**再添一个。

## 设置

**设置**有四个标签页。改动立即生效并保存。

- **常规** — 界面语言。
- **声音** — 音效、音乐和环境音的开关与音量。
- **显示** — 窗口模式（窗口化、最大化、无边框或独占全屏）、显示器、窗口大小、V-Sync 和帧率上限，外加**重置显示设置**。
- **模组** — 已安装模组添加的设置页面，带**恢复默认值**。

![显示标签页：窗口模式、显示器、窗口大小、V-Sync 和帧率上限。](assets/settings-display.jpg)

![模组标签页：Menu 模组自己的页面，有“Data of disabled mechanics”和清除按钮。](assets/settings-mods.jpg)

Menu 在**模组**标签页上的自家页面是**已停用机制的数据 → 清除**：它会从所有存档中删除已不属于任何游戏的模组数据。确定后再用：重新启用的机制会从头开始。

## Menu 依赖什么

Menu 负责绘制界面并决定每个按钮的行为。游戏列表及其就绪状态来自合集；启动、切换和保存游戏由引擎的游戏会话与存档服务完成；标题画面音乐是 Music Pack 的 `MainMenu` 播放列表，Menu 依赖它。**模组与合集**由 Mod Manager 提供。

## 给模组作者：添加按钮或设置页面

按钮来自注册表，而不是写死的界面，因此模组可以添加、替换或重新排列它们。Mod Manager 用 manifest 里的一个 `main_menu` 条目添加自己的按钮：

```json
"main_menu": [
  {
    "id": "mods_hub",
    "scene_path": "scenes/mods_hub_screen.tscn",
    "button": { "icon": "mod_manager", "locale": "mod_manager/menu_title", "index": 100 }
  }
]
```

当模组在模组设置注册表中登记了设置定义时——就像 Menu 为自己的清除操作所做的那样——它的设置就会出现在**模组**标签页。按钮和设置的文案来自模组自己的本地化。

## 出现问题时

1. **开始游戏下面没有游戏。** 没有安装或启用任何“游戏”类型的合集；请打开**模组与合集**。
2. **游戏卡片显示缺少模组或版本不兼容。** 使用**安装缺失项**，或点**配置**查看问题。
3. **没有“继续”按钮。** 它在你至少玩过一次之后才会出现。
4. **窗口记不住大小。** 检查**显示 → 窗口模式**；窗口大小只对窗口化模式生效。
