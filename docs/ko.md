# Menu — 메인 메뉴, 게임 선택, 저장, 설정

Menu는 여러분이 가장 먼저 보는 화면입니다. **플레이**, **불러오기**, **설정**, **모드와 컬렉션**, **나가기**가 놓인 타이틀 메뉴입니다. 설치된 게임을 골라 시작하거나 멈췄던 지점에서 이어하고, 저장 파일을 불러오고, 언어·소리·화면 설정을 바꿀 수 있습니다. 다른 모드가 자기 버튼과 설정 페이지를 추가할 수도 있습니다.

Menu는 항상 로드되는 셸의 일부이므로 어떤 게임을 시작하기 전부터 자리하고 있습니다.

![메인 메뉴: 왼쪽에 Play, Load, Settings, Mods & Collections, Exit, 오른쪽에 Cthangover 타이틀 아트.](assets/main-menu.jpg)

## 게임 시작하기

**플레이**를 누르면 **게임 선택**이 열립니다. 컬렉션의 게임은 각자 커버, 설명, 준비 상태, 저장 수가 붙은 카드로 표시됩니다.

![게임 선택의 두 장의 카드: Cthangover와 My Novel, 각각 "Ready to play", "No saves", New game과 Configure 버튼.](assets/game-picker.jpg)

- **새 게임**은 게임의 첫 장면부터 시작합니다. 메뉴는 같은 창에서 그 게임의 모드 세트로 바뀝니다. 재시작이 없습니다.
- 카드의 **이어하기**는 그 게임의 가장 최근 저장을 이어서 합니다. **저장 파일**은 목록을 보여 줍니다.
- **빠진 것 설치**는 게임에 필요한 모드가 없을 때 나타나 다운로드합니다.
- **구성**은 모드 관리자에서 게임 구성을 엽니다.

메뉴를 보고 있는 동안 게임들의 모드가 백그라운드에서 준비됩니다. 아래 힌트가 언제 시작이 빨라지는지 알려 줍니다.

메인 메뉴의 **이어하기**는 한 번이라도 플레이하면 나타납니다. 마지막으로 쓴 게임과 저장으로 돌아갑니다.

## 저장 불러오기

**불러오기**는 한 번에 한 게임의 저장을 보여 줍니다. 위의 선택기에서 게임을 고르고 저장을 클릭하면 불러옵니다.

![My Novel의 불러오기 창. 저장 "Day 1, 00:00" 하나와 힌트 "Click a save to load it".](assets/load.jpg)

저장 이후 게임의 모드가 바뀌었다면 **게임이 바뀌었습니다** 창이 추가된 것(처음부터 시작), 제거된 것(데이터는 보관되고 다시 켜면 돌아옴), 업데이트된 것을 나열하고 불러오기 전에 저장을 백업합니다. 게임이라는 개념 이전의 저장은 **게임이 없는 저장 파일** 아래에 나타납니다. 어느 게임에 속하는지 고르면 파일이 그곳으로 옮겨집니다.

게임 중에는 인게임 메뉴의 같은 창으로 저장하고 불러옵니다. 슬롯을 클릭해 저장하고, 사용 중인 슬롯은 확인 후 덮어쓰며, **+ 새로 저장**으로 하나 더 만듭니다.

## 설정

**설정**에는 탭이 넷 있습니다. 변경 사항은 곧바로 적용되고 저장됩니다.

- **일반** — 인터페이스 언어.
- **소리** — 효과음, 음악, 앰비언스의 켜기/끄기와 음량.
- **화면** — 창 모드(창 모드, 최대화, 테두리 없음, 전용 전체 화면), 모니터, 창 크기, V-Sync, 프레임 제한, 그리고 **화면 설정 초기화**.
- **모드** — 설치된 모드가 추가하는 설정 페이지와 **기본값으로**.

![화면 탭: 창 모드, 모니터, 창 크기, V-Sync, 프레임 제한.](assets/settings-display.jpg)

![모드 탭: Menu 모드 자신의 페이지. "Data of disabled mechanics"와 정리 버튼.](assets/settings-mods.jpg)

**모드** 탭의 Menu 자신의 페이지는 **비활성화된 메카닉의 데이터 → 정리**입니다. 더 이상 게임에 속하지 않는 모드의 데이터를 모든 저장에서 지웁니다. 확신이 들 때만 쓰세요. 다시 켠 메카닉은 처음부터 시작합니다.

## Menu가 의지하는 것들

Menu는 화면을 그리고 각 버튼이 무엇을 하는지 정합니다. 게임 목록과 준비 상태는 컬렉션에서 오고, 게임의 시작·전환·저장은 엔진의 게임 세션과 저장 서비스가 맡습니다. 타이틀 화면 음악은 Menu가 요구하는 Music Pack의 `MainMenu` 플레이리스트입니다. **모드와 컬렉션**은 Mod Manager가 제공합니다.

## 모드 제작자를 위해: 버튼이나 설정 페이지 추가하기

버튼은 고정된 화면이 아니라 레지스트리에서 옵니다. 그래서 모드가 추가하거나 바꾸거나 순서를 바꿀 수 있습니다. Mod Manager는 manifest의 `main_menu` 항목으로 자기 버튼을 더합니다:

```json
"main_menu": [
  {
    "id": "mods_hub",
    "scene_path": "scenes/mods_hub_screen.tscn",
    "button": { "icon": "mod_manager", "locale": "mod_manager/menu_title", "index": 100 }
  }
]
```

모드의 설정은 그 모드가 모드 설정 레지스트리에 설정 정의를 등록하면 **모드** 탭에 나타납니다. Menu가 정리 액션으로 하는 일과 같습니다. 버튼과 설정의 문구는 모드 자신의 로컬라이제이션에서 옵니다.

## 문제가 생겼을 때

1. **플레이 아래에 게임이 없다.** 종류가 *게임*인 컬렉션이 설치·활성화되어 있지 않습니다. **모드와 컬렉션**을 여세요.
2. **게임 카드에 빠진 모드 또는 호환되지 않는 버전이 표시된다.** **빠진 것 설치**를 쓰거나 **구성**으로 문제를 확인하세요.
3. **이어하기가 없다.** 한 번이라도 플레이하면 나타납니다.
4. **창이 크기를 유지하지 않는다.** **화면 → 창 모드**를 확인하세요. 창 크기는 창 모드에서만 적용됩니다.
